## Project Overview
This repository contains a two-page semantic HTML portfolio website built completely without CSS as required by the Chapter 2 (Part I) curriculum. The portfolio features:

- **index.html**: Main portfolio covering biographical information, technical skills, featured software projects, university academic records, and interactive contact channels.
- **projects.html**: Dedicated software projects catalogue detailing Simple Calculator, Library Management System, Quizcamp, and GPA Calculator with architecture steps and technology breakdowns.

## Lab Implementation Summary

| Lab | Milestone | Key Features |
| :---: | :--- | :--- |
| **Lab 0** | Setup | Initialized clean repository structure with assets and media. |
| **Lab 1** | Document Structure | Standard HTML5 skeleton (DOCTYPE html, lang="en", UTF-8 charset). |
| **Lab 2** | Heading Hierarchy | Proper outline (h1 to h3), paragraphs, hr dividers, and br line breaks. |
| **Lab 3** | Text Formatting & Code | Semantic formatting (strong, em, mark, sup, sub), quotes (blockquote, q, cite), and code snippets (pre, code). |
| **Lab 4** | Hyperlinks | Relative page links, in-page navigation anchors (#about, etc.), mailto, tel, and file downloads. |
| **Lab 5** | Images & Media | Profile picture, project screenshots, tab favicon, and coordinate-mapped map banner. |
| **Lab 6** | Lists | Grouped nested skills (ul), ordered learning roadmap (ol), and tools glossary (dl). |
| **Lab 7** | Complex Tables | Academic record table (thead, tbody, tfoot, rowspan, colspan) and Project Summary table. |
| **Your Turn** | Lab Extensions | Second-language code snippet (C++), external W3C standards link, addition of Quizcamp and GPA Calculator with build steps. |
| **Personal** | Personalization | Custom avatar, authentic AASTU courses, A2SV highlights, real project screenshots, and direct resume download. |
